# 保密协议（NDA）关键要素

## 保密协议必备条款

### 1. 保密信息的定义
明确界定保密信息的范围，包括但不限于：
- 技术信息：技术方案、工程设计、电路设计、制造方法、工艺流程、技术指标、计算机软件、数据库、研究开发记录、技术报告、检测报告、实验数据、试验结果、图纸、样品、模型、操作手册、技术文档
- 经营信息：客户名单、采购资料、定价政策、财务资料、进货渠道、产销策略、招投标中的标底及标书内容

### 2. 保密义务
- 未经披露方书面同意，接收方不得向任何第三方泄露保密信息
- 接收方应采取不低于保护自身同等重要信息的谨慎程度保护保密信息
- 仅限有必要知悉的员工接触保密信息，并确保该等员工遵守保密义务
- 不得将保密信息用于约定目的之外的任何用途

### 3. 保密期限
- 一般约定为合同有效期内及合同终止后2-5年
- 对于商业秘密，保密义务持续至该信息进入公有领域

### 4. 例外情形
以下信息不属于保密信息：
- 披露时已为公众所知的信息
- 非因接收方过错而进入公有领域的信息
- 接收方在披露前已合法持有的信息
- 接收方从有权披露的第三方合法获取的信息
- 依法或依监管要求必须披露的信息

### 5. 违约责任
- 停止侵害、消除影响
- 赔偿损失（包括直接损失和间接损失）
- 支付约定违约金
- 承担维权合理费用（律师费、诉讼费等）

### 6. 争议解决
- 协商解决
- 向有管辖权的人民法院提起诉讼
- 提交仲裁委员会仲裁
